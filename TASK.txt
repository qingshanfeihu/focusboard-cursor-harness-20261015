项目：FocusBoard，本地任务看板 Web 应用。
用户：一个人管理项目任务，需要清楚、精致、可靠、易用的日常工具。
技术：React + TypeScript + Vite；本地运行，无后端、账号或外部 API，不用远程字体或图片。自行选择简洁的设计风格。
必需功能：
1. 创建、编辑、删除任务。字段：标题（必填，去掉首尾空白）、描述、状态（待办/进行中/完成）、优先级（低/中/高）、可选截止日期、标签。
2. 看板和列表两种视图；搜索标题/描述；状态、优先级、标签筛选；截止日期排序；筛选可以组合和清除。
3. localStorage 持久化，刷新保留数据；损坏的保存内容不白屏。首次提供少量演示数据，并可清空。
4. 概览：任务总数、完成率、逾期任务数。完成的任务不算逾期，截止日当天不算逾期。
5. JSON 导入/导出。导入先校验，错误时清楚提示且保留原有数据。导出再导入应保留全部任务字段。
6. 桌面和 375px 手机均可用；键盘可完成基本任务；表单有标签、错误提示；空状态、确认删除等完整。
7. 有意义的自动化测试，覆盖核心行为与边界；生产构建成功。README 说明启动、测试、构建、功能和已知限制。
8. 最终交付 GitHub：新建独立仓库，包含有效 CI，走分支、PR、CI 检查、合并到 main 的流程。GitHub owner 为当前 gh 登录账户。仓库名在交付阶段另行提供。全部代码都是本次合成示例，可以公开。不要购买任何服务。
执行：先 Plan，给出需求拆解、架构、实现步骤、风险和具体验收方法；此阶段不要实现应用。计划完成后等待我的实施指令。
实现阶段应自主创建代码、运行测试和构建、用浏览器实际验证，并诚实说明任何没完成的部分。不要只写方案、用空按钮或只报告“应该通过”。
环境：独立空白 Git 工作区已经初始化。Node.js 24 与 npm 位于 /Users/qingshanfeihu/.local/node-v24.21.0/bin；若 PATH 缺少它们，请将此目录用于本项目命令。gh 已登录，可用于后续新建仓库与 PR。
